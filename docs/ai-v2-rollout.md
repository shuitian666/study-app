# AI 模块重整：实现与验收

## 已实现

- AI 中心统一为「问一问 / 陪我学 / 专业工具」，沿用现有主题。
- 刷题、知识点和卡片学习可带入上下文求助。手机为底部抽屉，桌面为侧面板；提交答案前不传入正确答案。
- 普通问答和学习导师共用对话组件；回答完成后由用户主动生成练习或确认加入知识库，不自动出题。
- 模型请求必须登录。对话、消息、学习计划检查点和总结按账号存储于服务端 SQLite。
- 本地学习计划按账号幂等迁移；云端进度采用版本检查，冲突时明确要求重新加载。删除有墓碑，旧数据不会再次导入。
- 总结保存与计划结束在一个事务内完成，同一账号同一 sessionId 重试不会产生重复总结。
- 统一流式解析，处理 UTF-8 分片、停止、部分回答和异常；错误不会被 done 标记吞掉，也不会以模拟回答掩盖失败。
- 自定义接口仅允许公网 HTTPS；拒绝私网、回环、重定向，连接固定至已验证 IP，避免 DNS 重绑定。密钥仍由现有服务端加密机制管理。

## 额度与兼容

| 等级 | 最近 5 小时 | 最近 7 天 |
| --- | ---: | ---: |
| 1–4 | 20 | 120 |
| 5–9 | 30 | 200 |
| 10–19 | 45 | 320 |
| 20–39 | 65 | 480 |
| 40+ | 90 | 700 |

两个窗口都采用滑动窗口，均需有足够点数。问答/导师/解析/单题/知识点讲解 1 点，练习组 2 点，计划/章节综合/求真报告 3 点。历史、总结保存和普通求真检索不扣点。

上游接受请求前失败退回预留点数；接受后中断仍计点。服务进程意外退出的预留请求在 5 分钟后标为中断并保留计费。相同请求标识及内容可重放已完成结果，点击重新生成是新请求、可能再次扣点。

自定义 Key 不消耗平台点数，但保留每账号最多 3 个并发、每 5 分钟 60 次请求的安全限制。等级从服务端同步学习记录和资产计算，不信任请求传入的 level；学习记录本身沿用现有同步系统的可信边界，不属于防作弊账本。

保留 `/api/chat`、`/api/quiz`、`/api/explain` 和学习接口，旧客户端仍需登录并受同一额度约束。`AI_V2_ENABLED=false` 只回退 AI 中心界面，不关闭鉴权、额度或删除云端数据。`AI_QUOTA_TIERS` 可覆盖五档配置，格式为二维数组 `[等级起点,5小时点数,7天点数]`，第一档必须从 1 开始。

## 验证方法

2026-09-21 验证结果：前端 12 组共 50 项、后端 77 项全部通过；生产构建、新增 AI 模块静态检查、浏览器回归通过，页面运行错误为 0。截图已人工检查。

1. `npm test`：前端单元测试与后端测试。涵盖额度窗口、并发预留、幂等请求、账号隔离、版本冲突、墓碑迁移、总结重试、题目结构校验、安全 URL、流式分片及 HTTP 路由。
2. `npm run build`：类型检查与生产构建。
3. `npx eslint src/features/ai src/components/ai/StudyTutorPanel.tsx src/services/aiService.ts src/services/aiStudyService.ts`：新增 AI 模块及相关服务的静态检查。不是全仓库 lint 通过的声明。
4. 先运行 `node scripts/ai-verification-server.mjs`，另一个终端运行 `node scripts/verify-ai-v2.mjs`。使用临时数据库、测试账号和模拟上游，不连接真实模型；需要本机 Playwright Chromium。截图在 `output/ai-v2/`。
5. 浏览器覆盖登录、中心入口、390/768/1440 宽度、流式回答落库及恢复、异常中断、停止、上下文抽屉、Tab 焦点循环和 Escape 关闭；检查页面运行错误。

Figma 页面参考快照：https://www.figma.com/design/6aLo4zoDpipjNIFVwVSM13?node-id=1-2 。这是从实际页面捕获的布局参考，不是重新制作的组件库。

## 上线步骤与边界

- 本次没有部署、修改生产配置或调用真实付费模型。
- 上线前备份现有 SQLite 数据目录与加密密钥，先在测试环境启动；新增表由服务启动时创建，不重写旧学习数据。
- 用真实平台 Key 验证一次问答、计划、练习和章节综合，以及实际使用的自定义接口协议和取消行为。此次模拟测试不能证明模型输出质量或第三方兼容性。
- 先小范围开放，观察 `ai_request` 日志及 `ai_usage_events` 的失败码、耗时、预留滞留、额度拒绝；必要时用开关回退中心界面。日志不输出正文或 Key。流式 token 数尚未统计，不可将空值当作真实零成本。
- 跨设备恢复目前以知识点/章节完成检查点为准；未完成知识点内的题目选择与生成内容不做逐题云端续接，重新进入可能重新生成并扣点。离线不发起 AI 请求，也不保证离线阅读云端历史。
- 尚未做真实 Android 设备、真实断网切换、第三方模型及生产负载验证；以上是上线前剩余验收项。
